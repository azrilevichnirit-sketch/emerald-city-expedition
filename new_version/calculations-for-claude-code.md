# לוגיקת חישובים — משלחת אל עיר האזמרגד

---

## ניקוד כלים

כל משימה:
- כלי 1 = 0 נקודות
- כלי 2 = 1 נקודה
- כלי 3 = 2 נקודות

---

## 1. סיכון (Risk Score)

**משימות:** 1, 4, 8, 11, 14
**מתודולוגיה:** Holt & Laury (2002) — בחירות חוזרות בין אפשרויות עם רמות סיכון שונות

```
Risk Score = Σ choiceᵢ / 5
             i ∈ {1,4,8,11,14}
```

טווח: 0 עד 2

| ציון | משמעות |
|------|--------|
| 0 – 0.7 | שונא סיכון גבוה |
| 0.7 – 1.3 | ניטרלי |
| 1.3 – 2 | פתוח לסיכון |

---

## 2. יציבות (Stability Score)

**משימות:** 2, 6, 9, 13
**מתודולוגיה:** Samuelson & Zeckhauser (1988) — שיעור בחירות בסטטוס קוו

```
Stability Score = Σ choiceᵢ / 4
                  i ∈ {2,6,9,13}
```

טווח: 0 עד 2

| ציון | משמעות |
|------|--------|
| 0 – 0.6 | שומר על הקיים, Status Quo Bias גבוה |
| 0.6 – 1.3 | מאוזן |
| 1.3 – 2 | נוטה לשינוי |

---

## 3. אימפולסיביות (Impulse Score)

**משימות לבדיקה:** 5, 10
**מתודולוגיה:** Dickman (1990) — שילוב בחירה מסוכנת עם זמן תגובה מתחת לחציון האישי

**שלב 1 — חציון מ-13 המשימות (ללא 5 ו-10):**
```
median_time = median(t₁,t₂,t₃,t₄,t₆,t₇,t₈,t₉,t₁₁,t₁₂,t₁₃,t₁₄,t₁₅)
```

הטיימר מתחיל ברגע שהכלים מופיעים.

**שלב 2 — חישוב δ למשימות 5 ו-10:**
```
δᵢ = 2   אם tᵢ < median_time וכלי = 3
δᵢ = 1   אם tᵢ < median_time וכלי = 2
δᵢ = 0   אחרת
```

**שלב 3 — ציון סופי:**
```
Impulse Score = Σ δᵢ / 2
                i ∈ {5,10}
```

טווח: 0 עד 2

| ציון | משמעות |
|------|--------|
| 0 – 0.5 | אימפולסיביות נמוכה |
| 0.5 – 1.2 | בינונית |
| 1.2 – 2 | אימפולסיביות גבוהה |

---

## 4. FOMO (FOMO Score)

**משימות:** 3, 7, 12, 15
**מתודולוגיה:** Przybylski et al. (2013) — שיעור בחירות שנובעות מהשפעת העדר

```
FOMOᵢ = choiceᵢ   (0, 1, או 2)

FOMO Score = Σ FOMOᵢ / 4
             i ∈ {3,7,12,15}
```

טווח: 0 עד 2

| ציון | משמעות |
|------|--------|
| 0 – 0.4 | עצמאי, לא מושפע מהעדר |
| 0.4 – 1.2 | בינוני |
| 1.2 – 2 | מושפע מאוד מהעדר |

---

## 5. זמני תגובה גולמיים

```
tᵢ = זמן מרגע הופעת הכלים עד בחירה במשימה i (במילישניות)
```

נשמר עבור כל 15 המשימות.
המדד הנגזר מזמני תגובה ייכנס לתוקף בשלב מאוחר יותר לאחר צבירת נתונים.
